Cài đặt trong 4 bướcInstall in 4 steps

Vì không qua Google Play, Android sẽ hỏi vài lần. Đây là thông báo bình thường với mọi app tải ngoài cửa hàng. Since it doesn't come from Google Play, Android will ask a few times. This is normal for any app installed outside the store.

  1. Bấm "Tải file APK"Tap "Download APK"
    Nếu trình duyệt báo "File này có thể gây hại", chọn Vẫn tải xuống. If the browser warns "This file might be harmful", choose Download anyway.
  2. Mở file vừa tảiOpen the downloaded file
    Bấm vào thông báo tải xong, hoặc mở ứng dụng Tệp / Quản lý tệp → thư mục Download → dau-tu-tu-dau.apk. Tap the download-complete notification, or open the Files app → Download → dau-tu-tu-dau.apk.
  3. Cho phép cài ứng dụngAllow installing apps
    Lần đầu, máy hỏi có cho trình duyệt (hoặc Quản lý tệp) cài ứng dụng không. Bấm Cài đặt → bật Cho phép từ nguồn này → quay lại. The first time, your phone asks whether the browser (or Files app) may install apps. Tap Settings → turn on Allow from this source → go back.
  4. Cài và chơiInstall and play
    Bấm Cài đặt. Nếu Google Play Protect cảnh báo ứng dụng lạ, chọn Thêm chi tiết → Vẫn cài đặt. Tap Install. If Google Play Protect warns about an unknown app, choose More details → Install anyway.

Máy Xiaomi / Redmi / POCO: máy có thể quét bảo mật hoặc đếm ngược vài giây trước khi cho cài, đợi hết rồi bấm Tiếp tục. Xiaomi / Redmi / POCO: the phone may run a security scan or count down a few seconds; wait, then tap Continue.

Câu hỏi thường gặpFAQ

Cập nhật bản mới thế nào?How do I update?

Quay lại trang này, tải file APK mới và cài đè lên bản cũ, ván chơi giữ nguyên. Đừng gỡ game trước khi cài: gỡ là xoá hết dữ liệu trên máy (hãy sao lưu trong Cài đặt trước). Come back here, download the new APK and install it over the old one; your game is kept. Don't uninstall first: that deletes your data on the phone (back up in Settings first).

Mua Premium hoặc xuất thân thế nào?How do I buy Premium or a background?

Bấm nút Mua trong game, game hiện mã QR. Quét bằng app ngân hàng bất kỳ và giữ nguyên nội dung chuyển khoản (mã bắt đầu bằng IL). Khoảng 1 phút sau gói tự mở. Lỡ đóng game thì lần mở sau gói vẫn được trao; chưa thấy thì bấm Khôi phục giao dịch. Chỉ hỗ trợ tài khoản ngân hàng Việt Nam. Tap Buy in the game and it shows a QR code. Scan it with any Vietnamese banking app and keep the transfer note unchanged (a code starting with IL). About a minute later it unlocks. If you closed the game, it is delivered next time; otherwise tap Restore purchases. Vietnamese bank accounts only.
